# Pilot Evaluation — Rating Form (template)

**Study title**: Does linguistically-grounded adaptive explanation help readers
understand difficult English sentences?

**Instructions for participants**:
You will read 10 English sentences. For each sentence you will see **two
explanations** (Version A and Version B). Please read both, then answer:

1. **Clarity rating** — rate each version separately on how clear and easy to
   understand the explanation is: 1 (very unclear) – 5 (very clear).
2. **Preference** — which version did you find more helpful? (A / B / no difference)
3. **Comprehension check** — answer one short question about the sentence meaning.

**Counterbalancing**: half of the participants receive A = baseline first;
the other half receive B = LinguaMind adaptive first. Use two form variants.
